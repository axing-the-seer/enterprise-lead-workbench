# 企业名单工作台

企业名单工作台是一套可独立运行的 Web 软件。本地版首次只设置一个访问密码，不需要邮箱账号。完成数据源初始化后，用户不依赖 Agent 也可以通过界面完成企业名单查询、文件导入、字段映射、规则执行、来源核验、证据审阅、导出和 HTML 报告。

WorkBuddy、Codex 或其他 AI 客户端只是可选入口。它们通过同一套受控 MCP/REST 服务读取名单与任务状态，不拥有另一份业务数据。

## 核心流程

1. 本机用户设置访问密码，系统自动创建内部身份和工作空间。
2. 用户检查并验证获客助手、企查查、文件导入和 Ego Lite。
3. 用户通过获客助手查找企业，或上传 CSV/XLSX/JSON 名单。
4. 系统保存原始来源快照，按版本化规则映射字段并保留冲突。
5. 用户按需调用企查查核验工商登记信息。
6. 用户对单家企业调用 Ego Lite，生成带证据和不确定性说明的 HTML 报告。
7. 名单可从 Web UI 导出为 CSV、XLSX、JSON；Agent 通过同一业务接口读取。

## 本地启动

需要 Node.js 22、Docker 和 Make：

```sh
npm ci
npm run start:local
```

默认 Web UI：`http://127.0.0.1:3101/`。首次打开时设置一个至少 12 位的访问密码；以后只需用它解锁本机工作台。

## 数据可信边界

- 企业必须来自获客助手、企查查或用户上传，不由模型补造。
- 缺失字段表示未知，不代表不存在或无风险。
- 企查查与获客助手事实按来源独立保存；显示优先级不会删除冲突值。
- 网页搜索只为已入库企业补充证据，不创建企业，不覆盖工商事实。
- 凭证只存在服务端 Secret/Vault；浏览器、日志、导出和 Skill 包不保存明文 Key。
